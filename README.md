# NEXA AI

Android assistant app (Kotlin, Jetpack Compose, `com.nexa.ai`). This milestone delivers the
**approved logo, the ~3 second Hologram Reveal opening, and the dashboard it hands over to**.
See `docs/FEATURE_STATUS.md` for what exists and `docs/TEST_REPORT.md` for what was verified.

- Build: `docs/BUILD_TERMUX.md`
- Opening flow: `NexaRoot.kt` -> `branding/NexaStage.kt` -> `branding/OrbRenderer.kt`
- Timing: `branding/OpeningTimeline.kt`
- Original logo and references (untouched): `branding/reference/`
- Asset scripts: `tools/`
